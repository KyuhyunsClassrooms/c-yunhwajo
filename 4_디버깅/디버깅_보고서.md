# 4. 디버깅 보고서 (10점)

> 💡 **디버깅이란?** 프로그램에서 발생한 오류(버그)를 찾아내고 고치는 과정입니다.

---

## 📝 작성 정보

#1 작성 날짜: 2025.11.17

1) 어떤 문제가 발생했나요?

입력값을 하나만 입력하면 프로그램이 잘못된 값을 읽거나 무한 반복되는 문제가 발생함.

2) 오류가 발생한 코드
scanf("%d %d %d", &a, &b, &c);

3) 왜 오류가 생겼나요?

입력을 3개 동시에 받도록 되어 있었는데,
사용자가 A, B, C를 한 줄에 모두 입력하지 않고 엔터를 여러 번 입력할 경우
버퍼에 데이터가 남거나 입력이 꼬이는 문제가 발생함.

4) 어떻게 고쳤나요?

입력 유효성 검사를 while 문으로 감싸고,
A/B/C가 0 또는 1이 아닐 때 메시지를 출력하도록 변경.

while (1) {
    printf("A, B, C 입력 (0 또는 1): ");
    scanf("%d %d %d", &a, &b, &c);

    if ((a == 0 || a == 1) &&
        (b == 0 || b == 1) &&
        (c == 0 || c == 1)) {
        break;
    }
    printf("잘못된 입력입니다. A, B, C는 0 또는 1이어야 합니다.\n");
}

5) 고친 후 결과

 정상적으로 작동함.

## 💭 디버깅하면서 배운 점

- 입력값을 받을때는 유효한지 반드시 확인해야 한다는 것을 배웠다.
- 논리 연산은 입력 값이 정확해야 원하는 결과가 나온다는 점을 깨달았다.
- 작은 조건식 하나가 프로그램 전체 흐름을 바꿀 수 있다는것을 느꼈다.
