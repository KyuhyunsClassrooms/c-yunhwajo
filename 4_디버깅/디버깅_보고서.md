# 4. 디버깅 보고서 (10점)

> 💡 **디버깅이란?** 프로그램에서 발생한 오류(버그)를 찾아내고 고치는 과정입니다.

---

## 📝 작성 정보

#1 작성 날짜: 2025.11.17

어떤 문제가 발생했나요?
사용자가 A, B, C 입력 시 공백을 잘못 입력하거나 엔터를 여러 번 누르면 프로그램이 이상하게 동작하거나 반복 입력이 끝나지 않는 문제가 발생함.

오류가 발생한 코드

scanf("%d %d %d", &A, &B, &C);


왜 오류가 생겼나요?
scanf로 세 개를 동시에 받도록 되어 있었지만, 사용자가 한 줄에 모두 입력하지 않고 줄마다 나누어 입력하면 입력 버퍼에 남은 값 때문에 읽기 순서가 꼬이거나 무한 반복이 발생했음.

어떻게 고쳤나요?
while 문으로 입력 유효성을 검사하도록 수정하고,
A, B, C가 0 또는 1이 아닌 경우 경고 메시지를 출력하도록 변경.

while (1) {
    printf("A B C 입력 (각각 0 또는 1): ");
    scanf("%d %d %d", &A, &B, &C);

    if ((A == 0 || A == 1) &&
        (B == 0 || B == 1) &&
        (C == 0 || C == 1)) {
        break;
    }
    printf("잘못된 입력입니다! 0 또는 1만 입력해주세요.\n");
}


고친 후 결과

정상적으로 입력값을 처리하고, 잘못된 입력 시 재입력 가능함.

#2 작성 날짜: 2025.11.20

어떤 문제가 발생했나요?
X, Y 계산 후 출력 시 값이 예상과 다르게 나오거나, 일부 테스트에서 결과가 이상하게 표시됨.

오류가 발생한 코드

X = A && B || !B && C;
Y = A || C && !B;


왜 오류가 생겼나요?
연산자 우선순위를 고려하지 않아, AND와 OR 연산이 의도와 다르게 계산됨.

어떻게 고쳤나요?
괄호를 사용하여 계산 순서를 명시적으로 지정.

X = (A && B) || ((!B) && C);
Y = (A || C) && (!B);


고친 후 결과

계산 결과가 입력값에 맞게 정확하게 출력됨.

# 프로그램 테스트 결과

테스트 1

무엇을 테스트했나요? A, B, C를 한 줄에 입력

어떻게 테스트했나요? 1 0 1 입력

결과: 성공

테스트 2

무엇을 테스트했나요? A, B, C를 줄마다 따로 입력

어떻게 테스트했나요? 1 (엔터) 0 (엔터) 1 (엔터) 입력

결과: 성공

테스트 3

무엇을 테스트했나요? 잘못된 값 입력

어떻게 테스트했나요? 2 0 1 입력

결과: 경고 메시지 출력 후 재입력 가능

💭 디버깅하면서 배운 점

사용자 입력은 항상 유효성 검사를 해야 프로그램이 안정적으로 동작한다.

논리 연산 계산 순서를 잘못 이해하면 결과가 완전히 달라질 수 있음을 알 수 있었다.

작은 조건식이나 괄호 하나가 프로그램 전체 동작에 큰 영향을 미친다는 것을 알게 되었다.
