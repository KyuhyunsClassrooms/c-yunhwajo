# 1. 프로그램 설계서 (5점)

## 1. 프로젝트 주제

AND, OR, NOT 논리 게이트를 활용한 디지털 회로 시뮬레이션 프로그램

## 2. 핵심 기능 목록

(구현할 기능들을 순서대로 나열하세요.)
1.  사용자로부터 3개의 입력(A, B, C)을 받는다.

2. AND, OR, NOT 게이트를 조합하여 출력 X, Y를 계산한다.

 X = (A AND B) OR (NOT B AND C)

 Y = (A OR C) AND NOT B

3. 계산된 출력 X, Y를 화면에 출력한다.

4. 사용자가 원하는 경우 반복적으로 다른 입력값을 테스트할 수 있다.


## 3. 데이터 구조 설계

[1] 기본 변수 사용

bool A, B, C;  
bool X, Y;    
char choice;  


[2] 구조체 사용 

struct CircuitInput {
    bool A;
