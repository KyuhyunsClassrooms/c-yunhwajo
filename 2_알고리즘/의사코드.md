2. 알고리즘 (의사 코드)

[1] main 함수 전체 흐름
시작
반복 (사용자가 'n' 또는 'N' 선택할 때까지):
    "A, B, C 입력 (0 또는 1)" 메시지 출력
    A, B, C 입력 받기
    입력값을 bool 타입으로 변환 (0 -> false, 1 -> true)
    
    출력 X 계산:
        X = (A AND B) OR (NOT B AND C)
    출력 Y 계산:
        Y = (A OR C) AND NOT B

    출력 결과 화면에 표시:
        X 값 출력
        Y 값 출력

    "다른 입력으로 시뮬레이션 하시겠습니까? (y/n)" 메시지 출력
    사용자 선택 입력
반복 끝
프로그램 종료

[2] 핵심 기능 1: 입력값 처리 및 변환
시작
    사용자로부터 A, B, C 입력받기
    각 입력이 0이면 false, 1이면 true로 변환
종료

[3] 핵심 기능 2: 출력 계산
시작
    X 계산:
        X1 = A AND B
        X2 = NOT B AND C
        X = X1 OR X2

    Y 계산:
        Y1 = A OR C
        Y = Y1 AND (NOT B)
종료

[4] 핵심 기능 3: 결과 출력
시작
    화면에 출력:
        "X = ", X
        "Y = ", Y
종료

[5] 핵심 기능 4: 반복 시뮬레이션 처리
시작
    "다른 입력으로 시뮬레이션 하시겠습니까? (y/n)" 출력
    사용자 입력 확인
    만약 'y' 또는 'Y'이면:
        반복 계속
    아니면:
        반복 종료
종료

[6] 핵심 기능 5: 사용자 입력 유효성 검사 추가
시작
    반복 (A, B, C가 모두 유효한 입력값이 아닐 경우):
        사용자로부터 A, B, C 입력 받기
        만약 A, B, C가 0 또는 1이 아니면:
            "잘못된 입력입니다. A, B, C는 0 또는 1이어야 합니다." 메시지 출력
            A, B, C 다시 입력 받기
        아니면:
            A, B, C를 bool 타입으로 변환 (0 -> false, 1 -> true)
    종료
